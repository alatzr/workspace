# T1

这道题目是一道非常经典的表达式递归解析（语法树遍历）与数学维护（矩形/线性变换）结合的题目。
由于展开后的字符串长度可能极长（$`k \le 10^9`$ 且支持多层嵌套，展开长度轻松突破 $`10^{18}`$），我们**绝对不能直接把字符串展开**，而是需要利用**数学归纳与代数维护**，在解析表达式树的同时动态计算长度与位置加权和。
### 第一步：拆解题意与直观建模
首先剥离题目的表象，将其转化为数学与数据结构语言：
1. **题目要求维护的两个量**：
    对于一个展开后长度为 $`L`$ 的字符串 $`S`$，设其起始下标在全局偏移量为 $`B`$（即字符串在全局中的实际位置是 $`B+1, B+2, \dots, B+L`$）：
    - **总长度 $`L`$**：字符串包含的字符个数。
    - **位置加权和**：若局部加权和定义为 $`\sum_{i=1}^L i \cdot v_i`$，那么当该段字符串整体平移 $`B`$ 个单位后，全局加权和变成：

      $$\sum_{i=1}^L (B + i) \cdot v_i= B \sum_{i=1}^L v_i+ \sum_{i=1}^L i \cdot v_i$$

    - 因此，除了**长度 $`L`$** 和 **局部位置加权和 $`S_{pos}`$** 外，我们还必须维护一个关键量：**字符权值和 $`V = \sum_{i=1}^L v_i`$**！

1. **核心定义：一个表达式块的“三元组”信息**：
    任何一个表达式（无论是一个字母、一串连接，还是一个重复块 $`[E]k`$），在内部都可以抽象为一个结构体：
    - $`L`$：该表达式展开后的**总长度**。
    - $`V`$：该表达式展开后所有字符的**权值之和** ($`\sum v_i`$)。
    - $`S_{pos}`$：该表达式从局部下标 $`1 \dots L`$ 开始的**局部位置加权和** ($`\sum i \cdot v_i`$)。

### 第二步：从暴力到最优解（拼接与重复的数学推导）

#### 1. 表达式的“拼接”操作（$`\text{Concat}`$）

假设我们有两个连续的表达式块 $`A`$ 和 $`B`$：
- $`A`$ 的信息为 $`(L_A, V_A, S_{A})`$
- $`B`$ 的信息为 $`(L_B, V_B, S_{B})`$
当它们拼接成 $`A + B`$ 时：
- **新长度**：$`L_{new} = L_A + L_B`$
- **新权值和**：$`V_{new} = V_A + V_B`$
- **新位置加权和**：$`A`$ 占据位置 $`1 \dots L_A`$，$`B`$ 占据位置 $`L_A + 1 \dots L_A + L_B`$。

  $$S_{new} = S_A + \sum_{i=1}^{L_B} (L_A + i) \cdot v_{B, i} = S_A + L_A \cdot V_B + S_B$$

#### 2. 表达式的“重复”操作（$`\text{Repeat } k`$）

假设表达式 $`A = (L_A, V_A, S_A)`$ 被重复了 $`k`$ 次（即 $`[A]k`$）：
- **新长度**：$`L_{new} = k \cdot L_A \bmod MOD`$
- **新权值和**：$`V_{new} = k \cdot V_A \bmod MOD`$
- **新位置加权和**：考虑第 $`j`$ 次重复（$`j = 0, 1, \dots, k-1`$），这次重复相较于局部起始位置偏移了 $`j \cdot L_A`$：

```math
S_{new} = \sum_{j=0}^{k-1} \left( S_A + (j \cdot L_A) \cdot V_A \right) = k \cdot S_A + L_A \cdot V_A \cdot \sum_{j=0}^{k-1} j
```

其中 $`\sum_{j=0}^{k-1} j = \frac{(k-1)k}{2}`$。

**结论**：只要有了这套公式，无论是简单的单个字母，还是极其复杂的嵌套，都可以**在 $`O(1)`$ 时间内完成合并与重复**！

### 第三步：攻克核心难点 —— 语法树解析与流式处理

题目给出的字符串包含嵌套方括号，如何优雅地解析它？
1. **栈解析**：
    - 遇到小写字母 `a`~`z`：构造一个基础块 $`(L=1, V=val, S_{pos}=val)`$，然后与当前层已有的结果进行拼接。
    - 遇到 `[`：压栈，进入新的一层表达式解析。
    - 遇到 `]`：从输入流中读取紧随其后的数字 $`k`$，将当前层解析完毕的结构体执行“重复 $`k`$ 次”操作，然后弹栈，与上一层的结果进行拼接。
 
2. **注意模运算细节**：
    - 算式中包含 $`\frac{(k-1)k}{2} \bmod 998244353`$，需要对 $`2`$ 取逆元（即乘以 $`499122177`$）。
    - 输入的 $`k`$ 可能达到 $`10^9`$，注意先对 $`998244353`$ 取模，但在计算 $`\frac{(k-1)k}{2}`$ 时，要保留原数或者用模意义下的组合数公式计算。
### 第四步：完整参考代码（C++ 实现）

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cctype>

using namespace std;

const int MOD = 998244353;
const int INV2 = 499122177; // 2 在 MOD 998244353 下的乘法逆元

// 维护表达式块的核心数据结构
struct Block {
    long long L;     // 展开长度 mod MOD
    long long V;     // 权值和 mod MOD
    long long S;     // 位置加权和 mod MOD

    Block(long long l = 0, long long v = 0, long long s = 0) 
        : L(l % MOD), V(v % MOD), S(s % MOD) {}
};

// 拼接两个表达式块 A 和 B (即 A 后面紧跟 B)
Block merge_blocks(const Block& A, const Block& B) {
    Block res;
    res.L = (A.L + B.L) % MOD;
    res.V = (A.V + B.V) % MOD;
    res.S = (A.S + A.L * B.V % MOD + B.S) % MOD;
    return res;
}

// 将表达式块 A 重复 k 次 (即 [A]k)
Block repeat_block(const Block& A, long long k) {
    Block res;
    long long k_mod = k % MOD;

    res.L = A.L * k_mod % MOD;
    res.V = A.V * k_mod % MOD;

    // sum_j = (k - 1) * k / 2 % MOD
    long long sum_j = ((k_mod) * ((k_mod - 1 + MOD) % MOD) % MOD) * INV2 % MOD;

    // S_new = k * S_A + L_A * V_A * (k*(k-1)/2)
    long long part1 = k_mod * A.S % MOD;
    long long part2 = (A.L * A.V % MOD) * sum_j % MOD;
    res.S = (part1 + part2) % MOD;

    return res;
}

int main() {
    string expr;
    cin >> expr;
    int n = expr.length();
    vector<Block> st;
    st.push_back(Block(0, 0, 0)); // 栈底放全局最外层的 Block
    int i = 0;
    while (i < n) {
        if (expr[i] >= 'a' && expr[i] <= 'z') {
            int val = expr[i] - 'a' + 1;
            Block single_char(1, val, val);
            // 将当前字符与当前栈顶（当前括号层级）的 Block 拼接
            st.back() = merge_blocks(st.back(), single_char);
            i++;
        } else if (expr[i] == '[') {
            // 遇到 '['，压入一个新的空 Block 进入内层
            st.push_back(Block(0, 0, 0));
            i++;
        } else if (expr[i] == ']') {
            i++; // 跨过 ']'

            // 读取紧跟在 ']' 后面的数字 k
            long long k = 0;
            while (i < n && isdigit(expr[i])) {
                k = (k * 10 + (expr[i] - '0')) % MOD; // 实时取模，防止溢出
                i++;
            }
            // 弹出内层 Block 并重复 k 次
            Block sub_block = st.back();
            st.pop_back();
            Block repeated_sub = repeat_block(sub_block, k);
            // 拼接到上一层（即弹出后的新栈顶）
            st.back() = merge_blocks(st.back(), repeated_sub);
        }
    }
    Block ans = st.back();
    cout << ans.L << " " << ans.S << "\n";
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：
    字符串编码长度为 $`M \le 200000`$。由于指针 `ptr` 严格单向递增且每个字符只被处理一次，递归解析的开销为 $`O(M)`$。每次块合并与重复计算均在 $`O(1)`$ 时间内完成。
    因此总时间复杂度为 $`\mathcal{O}(M)`$，可以在 0.05 秒内轻松通过全套测试点。
- **空间复杂度**：
    递归调用的最大深度取决于方括号的嵌套深度，最坏情况下为 $`O(M)`$，栈空间占用几十 KB，远远低于 256 MiB 的限制。


# T2 两端取箱
这道题是一道非常经典的博弈论 DP（区间 DP + 记忆化搜索）问题。它在经典“区间博弈取数”的基础上，增加了方向依赖罚分 $`P`$ 的机制。
### 第一步：拆解题意与直观建模
我们先剥离题目的表象，将其翻译成标准的博弈 DP 模型：
1. **核心博弈规则**： 
    - 零和博弈问题：双方目标都是**最大化自己的得分与对方得分的差值**（即“己方 - 对方”）。
    - 初始有区间 $`[1, n]`$ 的箱子。每一步玩家可以从当前剩余区间的**左端**或**右端**取走一个箱子。
    - 特殊罚分：如果**本次取数的方向**（左 / 右）与**上一次取数的方向**（左 / 右）相同，则当前玩家的得分需要**扣除 $`P`$**。
    - 注意点：
        1. 第一步没有“上一次操作”，因此**不扣分**。
        2. **只剩 1 个箱子时，必须视作从左端取**。这意味着如果上一次也是从左端取的，取这最后一个箱子时**需要扣除 $`P`$**。
2. **状态依赖分析**：
    - 既然转移收益依赖于“上一次取的方向”，那么 DP 的状态就不能只记录剩余区间 $`[i, j]`$，**必须额外记录上一次操作的方向**。
    - 我们可以用一个维度 $`dir \in \{0, 1\}`$ 表示上一位玩家（即上一步）是从左端（$`0`$）还是右端（$`1`$）拿走的。

### 第二步：从暴力到最优解（区间 DP 状态设计）

#### 1. 暴力与递归状态（Subtask 1 - 3）

设函数 $`f(i, j, last\_dir)`$ 表示：当前剩余区间为 $`[i, j]`$，且**上一步被拿走的端点**是 $`last\_dir`$（$`0`$ 表示左，$`1`$ 表示右）时，**当前轮到的玩家**能够获得的最大“分差”（当前玩家得分 - 对方得分）。
- **第一步特例**：游戏刚开始时（区间为 $`[1, n]`$），没有上一步，我们可以特别规定一个状态 $`last\_dir = -1`$，表示无罚分历史。
#### 2. 状态转移推导

假设当前玩家面对区间 $`[i, j]`$，上一步方向为 $`last\_dir`$：
- **特例：$`i = j`$（只剩 1 个箱子）**：
    - 规则规定必须视作**从左端取**（$`dir = 0`$）。
    - 产生的额外罚分为：如果 $`last\_dir == 0`$，扣除 $`P`$；否则扣除 $`0`$。
    - 最终收益为 $`a_i - \text{penalty}`$。
- **一般情况：$`i < j`$**：
    - **选择 1：拿左端 $`a_i`$**：
        - 本次方向为 $`0`$。若 $`last\_dir == 0`$，罚分为 $`P`$，否则为 $`0`$。
        - 当前玩家收益为 $`a_i - \text{penalty} - f(i+1, j, 0)`$。
    - **选择 2：拿右端 $`a_j`$**：
        - 本次方向为 $`1`$。若 $`last\_dir == 1`$，罚分为 $`P`$，否则为 $`0`$。
        - 当前玩家收益为 $`a_j - \text{penalty} - f(i, j-1, 1)`$。
    - 当前玩家会在这两种选择中取 **极大值（$`\max`$）**。

### 第三步：攻克核心难点

1. **边界条件的“只剩一个箱子”陷阱**：
    - 题目明确写道：“只剩一个箱子时规定必须视作从左端取”。
    - **容易踩坑的地方**：如果上一次操作也是从左端取（$`last\_dir = 0`$），取这最后一个箱子**仍然需要扣除 $`P`$**！
    - 样例 1 解释中特别强调：“第一步不扣，即使规定为左取也不支付罚分”。因此第一步取单点不扣分，但非第一步时，若 $`last\_dir == 0`$，必须扣 $`P`$。

### 第四步：完整参考代码（C++ 实现）

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

const int MAXN = 2505;
const long long INF = 1e18;

int n;
long long P;
long long a[MAXN];

// dp[i][j][0] 表示区间 [i, j]，上一步取的是左端 (dir = 0) 时，当前玩家能获得的最大分差
// dp[i][j][1] 表示区间 [i, j]，上一步取的是右端 (dir = 1) 时，当前玩家能获得的最大分差
long long dp[MAXN][MAXN][2];

int main() {
    cin >> n >> P;
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }
    // 1. 初始化区间长度 len = 1 的情况（只剩 1 个箱子）
    // 规定必须视作从左端 (dir = 0) 取
    for (int i = 1; i <= n; ++i) {
        // 如果上一步也是左端 (last_dir = 0)，需要扣除 P
        dp[i][i][0] = a[i] - P;
        // 如果上一步是右端 (last_dir = 1)，不需要扣除 P
        dp[i][i][1] = a[i];
    }
    // 2. 按区间长度从 2 到 n 进行递推
    for (int len = 2; len <= n; ++len) {
        for (int i = 1; i <= n - len + 1; ++i) {
            int j = i + len - 1;
            // 针对上一步方向 last_dir 为 0 (左) 和 1 (右) 分别计算
            for (int last_dir = 0; last_dir < 2; ++last_dir) {
                // 选项 A: 拿左端 a[i] (本次方向为 0)
                long long penalty_L = (last_dir == 0) ? P : 0;
                long long val_L = (a[i] - penalty_L) - dp[i + 1][j][0];

                // 选项 B: 拿右端 a[j] (本次方向为 1)
                long long penalty_R = (last_dir == 1) ? P : 0;
                long long val_R = (a[j] - penalty_R) - dp[i][j - 1][1];

                dp[i][j][last_dir] = max(val_L, val_R);
            }
        }
    }
    // 3. 特殊处理最外层第一步 (区间为 [1, n]，没有上一步方向，不扣除任何罚分)
    if (n == 1) {
        // 第一步只有 1 个箱子，不扣分
        cout << a[1] << "\n";
    } else {
        // 第一步拿左端 a[1] (不扣分，后续转移 last_dir = 0)
        long long choice_L = a[1] - dp[2][n][0];
        // 第一步拿右端 a[n] (不扣分，后续转移 last_dir = 1)
        long long choice_R = a[n] - dp[1][n - 1][1];
        cout << max(choice_L, choice_R) << "\n";
    }
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：
    - 状态空间为 $`O(n^2)`$（两层循环枚举区间长度与左端点），每个状态转移为 $`O(1)`$。
    - 总时间复杂度为 $`\mathcal{O}(n^2)`$。对于 $`n = 2500`$，计算量约为 $`6.25 \times 10^6`$ 次，在 2.0 秒内轻松跑完。
- **空间复杂度**：
    - 使用静态三维数组 `dp[2505][2505][2]`，占用内存约 $`2505 \times 2505 \times 2 \times 8 \text{ Bytes} \approx 100 \text{ MB}`$，完全在 256 MiB 限制以内。

# T3 

这是一道典型的**字典序最小贪心构造**问题。
为了保证求出**字典序最小**的答案，我们在填第 $`1`$ 到第 $`n`$ 位时，策略非常直接：**从数值最小的可用数字开始试填**。但贪心不能“只顾眼前”。如果盲目填入当前最小的数，可能会导致后续位置**无法满足“相邻不相同”**，或者**某个数的频次超标**。

因此，核心逻辑是：**每尝试填入一个数 $`x`$，必须先预判“如果填了 $`x`$，剩下的数还能不能合法排完”。只要能，就确定填 $`x`$ 并直接进入下一位。**

### 第一步：如何预判剩余序列是否有解？

假设当前还剩 $`rem`$ 个位置，上一位刚刚填入的数是 $`last`$。
#### 1. 鸽巢原理（频次上限）
任何一个数字的出现次数 $`max\_cnt`$，都不能超过剩余位置的一半（向上取整）：

```math
max\_cnt \le \lfloor (rem + 1) / 2 \rfloor
```

#### 2. 关键陷阱：奇数位置 + 众数撞车

当剩余位置 $`rem`$ 是**奇数**（例如还剩 5 个位置：`_ _ _ _ _`），且某个众数的出现次数**恰好达到了上限** $`\lfloor (rem + 1) / 2 \rfloor`$ 时：

- 这个众数**必须占用所有的奇数位**（即剩余序列的第 1, 3, 5 位）。
- **这就强制要求剩余序列的第一位必须是这个众数**！
- **致命冲突**：如果这个众数恰好就是上一位填的数字 $`last`$，就会导致“相邻填了相同数字”。此时**无解**！

#### 判定函数 `isValid(rem, last)` 的充要条件：

1. $`max\_cnt \le \lfloor (rem + 1) / 2 \rfloor`$；
2. 如果 $`rem`$ 是奇数，且 $`max\_cnt == (rem + 1) / 2`$，则**这个众数不能等于 $`last`$**。

### 第二步：逐位贪心算法流程

1. **初始检查**：调用 `isValid(n, -1)`，如果最初就无解，直接输出 `-1`。
2. **逐位求解 ($`rem = n \to 1`$)**：
    - 在当前所有**仍有剩余数量**的数字中，**从小到大**遍历候选数字 $`x`$：
        - **排除非法情况**：如果是第一位（$`rem = n`$）且 $`x == F`$，跳过；如果 $`x == last`$，跳过。
        - **试填 $`x`$**：将 $`x`$ 的频次 $`-1`$。
        - **前瞻预判**：调用 `isValid(rem - 1, x)` 检查剩余状态。  
            - **合法**：确定当前位填 $`x`$，更新 $`last = x`$，退出当前位的尝试。
            - **不合法**：撤销试填（$`x`$ 的频次 $`+1`$），尝试下一个较大的候选数。
### 参考代码
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int n;
ll forbid;
map<ll, int> cnt;          // 记录每个数字及其剩余出现次数
set<ll> available;         // 当前还有剩余数量的数字（按字典序从小到大排列）
multiset<int> counts_set;  // 维护所有剩余数字的频次，用于 O(1) 获取最大频次 max_cnt

// 预判函数：检查在上一位填了 last 的情况下，剩余 rem 个位置是否能合法排完
bool isValid(int rem, ll last) {
    if (rem == 0) return true;
    // 1. 获取当前出现次数最多的数字的频次
    int max_cnt = *counts_set.rbegin(); 
    if (max_cnt > (rem + 1) / 2) return false;
    // 2. 关键陷阱：当剩余位置为奇数，且众数达到上限 (rem + 1) / 2 时
    // 众数必须被放置在剩余序列的第一位。如果这个众数恰好是 last，就会产生相邻冲突，导致无解
    if ((rem % 2 == 1) && (max_cnt == (rem + 1) / 2)) {
        if (last != -1 && cnt[last] == max_cnt) {
            return false;
        }
    }
    return true;
}

int main() {
    cin >> n >> forbid;
    cnt.clear();
    available.clear();
    counts_set.clear();
    for (int i = 0; i < n; ++i) {
        ll x;
        cin >> x;
        cnt[x]++;
    }
    // 初始化 available 和 counts_set
    for (auto [x, c] : cnt) {
        available.insert(x);
        counts_set.insert(c);
    }
    // 1. 初始全局合法性检查
    if (!isValid(n, -1)) {
        cout << -1 << "\n";
        return;
    }
    vector<ll> ans;
    ll last = -1;
    // 2. 逐位贪心构造
    for (int rem = n; rem >= 1; --rem) {
        bool ok = false;
        // 从小到大遍历当前可用的候选数字
        for (ll x : available) {
            // 首项限制与相邻不同限制
            if (rem == n && forbid > 0 && x == forbid) continue;
            if (rem < n && x == last) continue;
            // --- 试填 x ---
            int cur_c = cnt[x];
            counts_set.erase(counts_set.find(cur_c));
            cnt[x]--;
            if (cnt[x] > 0) counts_set.insert(cnt[x]);
            // 预判：检查试填后剩余 rem - 1 个位置是否有解
            if (isValid(rem - 1, x)) {
                ans.push_back(x);
                last = x;
                if (cnt[x] == 0) {
                    available.erase(x); // 数量扣光，移出可用集合
                }
                ok = true;
                break; // 贪心找到最小可用数字，直接确定，进入下一位
            }
            // 试填失败，撤销改动
            if (cnt[x] > 0) counts_set.erase(counts_set.find(cnt[x]));
            cnt[x]++;
            counts_set.insert(cnt[x]);
        }
        if (!ok) {
            cout << -1 << "\n";
            return;
        }
    }
    // 输出答案
    for (int i = 0; i < n; ++i) {
        cout << ans[i] << (i + 1 == n ? '\n' : ' ');
    }
}
```

### 复杂度分析

- **时间复杂度**：$`\mathcal{O}(n \log n)`$
    - 外层一共运行 $`n`$ 次循环。
    - 内层由于有 `isValid` 的严格把关，绝大多数情况下只需尝试 $`1 \sim 2`$ 个较小的候选数字；即使遇到必须强制填众数的情况，遍历也会在 $`O(1)`$ 次内结束。
    - `multiset` 维护频次的单次修改耗时 $`O(\log n)`$。
    - 整体耗时极短，可以非常轻松地通过 Subtask 4（$`n = 200000`$）。
- **空间复杂度**：$`\mathcal{O}(n)`$
    - 仅使用 `map`、`set` 和 `vector` 存储输入数据和答案，空间占用约 15 MB，远低于 512 MiB 的限制。

## 第四步：总结代码框架，强调易错点

1. **阶段一（定底线）：** `sort` 仅按 `r` 升序 $`\to`$ 跑并查集 $`\to`$ 图连通时，记录下当前的 $`r`$ 为 `R_opt`。
2. **阶段二（挑便宜）：** 把 `r > R_opt` 的边全扔掉 $`\to`$ 剩下的边 `sort` 仅按 `c` 升序 $`\to`$ 清空并查集，重新跑一遍 $`\to`$ 累加的 `c` 就是答案。

## 题目核心解析

本题要求在一张无向图中选出一棵生成树，优化目标有两个，且具有严格的**先后优先级**：
1. **第一优先级**：最小化生成树中的“最大风险值 $`r`$”。
2. **第二优先级**：在满足第一优先级的前提下，最小化生成树的总建设费 $`\sum c`$。
这实际上是瓶颈生成树（Bottleneck Spanning Tree）**与**最小生成树（MST）的结合。

## 为什么“双关键字排序”会 WA？

许多人拿到此题的第一反应是：对所有边按双关键字升序排序（先按 $`r`$ 排序，如果 $`r`$ 相同再按 $`c`$ 排序），然后跑一遍 Kruskal 算法。**这是一个经典的贪心陷阱。**

**反例：**

假设有 3 个站点，3 条边：
- 边 1：`1-2`，风险 $`r=10`$，费用 $`c=10000`$
- 边 2：`2-3`，风险 $`r=20`$，费用 $`c=10`$
- 边 3：`1-3`，风险 $`r=20`$，费用 $`c=10`$
如果按双关键字贪心，算法会优先强行连上极度昂贵的“边 1”（因为它的 $`r=10`$ 最小），再连上“边 2”。此时**最大风险为 20，总费用为 10010**。

但实际上，既然我们最终依然要承受 $`20`$ 的风险，我们完全可以舍弃昂贵的“边 1”，直接选择“边 2”和“边 3”。此时**最大风险依然是 20，但总费用降到了 20**。

**结论**：在第一优先级（最大风险）未突破底线的情况下，我们应该尽可能选择费用 $`c`$ 小的边，而不是无脑选择风险 $`r`$ 极小但极其昂贵的边。

## 正确解法：两阶段 Kruskal 算法
既然目标有严格的先后顺序，我们的算法也必须分为两步执行：

### 阶段一：确定“最小的最大风险” $`R_{opt}`$

我们要想知道最终生成树的最大风险底线是多少，可以先忽略费用 $`c`$，**只按风险 $`r`$ 升序排序**，跑一遍标准的 Kruskal。

当第 $`n-1`$ 条边成功加入并查集、使得全图刚好连通时，这条边的风险值 $`r`$ 就是本题的第一个答案——**最优瓶颈风险 $`R_{opt}`$**。

_(注意：如果遍历完所有边都无法凑够 $`n-1`$ 条，说明图不连通，直接输出 `-1 -1` 结束程序。)_

### 阶段二：在合法阈值内求“最小总费用”

既然我们已经确定，无论如何组网，最大风险必然会达到 $`R_{opt}`$，那么**图中所有满足 $`r \le R_{opt}`$ 的边，在第一阶段的考核中都是“合法且等价”的**。

因此，我们将所有 $`r \le R_{opt}`$ 的边单独提取出来，**只按费用 $`c`$ 升序排序**，清空并查集后，重新跑一遍 Kruskal。这次求出的总费用即为在最优风险下的最小总花费。

## 复杂度分析

- **时间复杂度**：
    - 第一阶段：排序耗时 $`\mathcal{O}(m \log m)`$，并查集 $`\mathcal{O}(m \alpha(n))`$。
    - 第二阶段：过滤边 $`\mathcal{O}(m)`$，对合法边排序耗时 $`\mathcal{O}(m \log m)`$，并查集 $`\mathcal{O}(m \alpha(n))`$。
    - 总体时间复杂度为 $`\mathcal{O}(m \log m)`$。在 $`m=140000`$ 时，常数极小，可在 0.1 秒内通过 2.0s 的时限。
- **空间复杂度**：存储 $`m`$ 条边占用 $`\mathcal{O}(m)`$，并查集占用 $`\mathcal{O}(n)`$，总空间复杂度 $`\mathcal{O}(n + m)`$，约 10MB，远低于 512MiB 限制。

## 完整 AC 代码 (C++)

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 边的结构体定义
struct Edge {
    int u, v;
    int r, c;
};

// 并查集结构，封装以支持两阶段重用
struct DSU {
    vector<int> parent;
    
    DSU(int n) {
        parent.resize(n + 1);
        for (int i = 1; i <= n; ++i) parent[i] = i;
    }

    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // 路径压缩
    }

    bool unite(int i, int j) {
        int root_i = find(i);
        int root_j = find(j);
        if (root_i != root_j) {
            parent[root_i] = root_j;
            return true;
        }
        return false;
    }
};

int main() {
    // 优化 I/O 读取速度
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    // 特例处理：只有 1 个点时，按题意直接输出 0 0
    if (n == 1) {
        cout << "0 0\n";
        return 0;
    }

    vector<Edge> edges(m);
    for (int i = 0; i < m; ++i) {
        cin >> edges[i].u >> edges[i].v >> edges[i].r >> edges[i].c;
    }

    // ==========================================
    // 阶段 1：找出“最小的最大风险” R_opt
    // ==========================================
    
    // 仅按风险 r 从小到大排序
    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.r < b.r;
    });

    DSU dsu1(n);
    int edge_cnt = 0;
    int R_opt = -1;
    
    for (const auto& e : edges) {
        if (dsu1.unite(e.u, e.v)) {
            edge_cnt++;
            if (edge_cnt == n - 1) {
                R_opt = e.r; // 找到使图连通的瓶颈风险
                break;
            }
        }
    }

    // 如果选出的边少于 n - 1，说明图不连通
    if (edge_cnt < n - 1) {
        cout << "-1 -1\n";
        return 0;
    }

    // ==========================================
    // 阶段 2：在合法阈值内（r <= R_opt），求最小总费用
    // ==========================================
    
    vector<Edge> valid_edges;
    for (const auto& e : edges) {
        if (e.r <= R_opt) {
            valid_edges.push_back(e);
        } else {
            // 因为 edges 已按 r 排序，遇到 r > R_opt 的边直接终止遍历
            break; 
        }
    }

    // 将这些合法的边，仅按建设费 c 从小到大排序
    sort(valid_edges.begin(), valid_edges.end(), [](const Edge& a, const Edge& b) {
        return a.c < b.c;
    });

    DSU dsu2(n);
    edge_cnt = 0;
    long long total_c = 0; // 注意：极端情况下费用总和可能超 2^31-1，需用 long long
    
    for (const auto& e : valid_edges) {
        if (dsu2.unite(e.u, e.v)) {
            edge_cnt++;
            total_c += e.c;
            if (edge_cnt == n - 1) {
                break;
            }
        }
    }

    // 输出最终的双指标
    cout << R_opt << " " << total_c << "\n";

    return 0;
}
```
